# Fonts on the How to use page

The page ships its own fonts, so it looks the same offline and on lab PCs without Google Fonts.

| Font | Files | Used for | Licence |
|---|---|---|---|
| Atkinson Hyperlegible Next, by the Braille Institute of America and Applied Design Works ([source](https://github.com/googlefonts/atkinson-hyperlegible-next)) | `atkinson-hyperlegible-next-latin-wght-normal.woff2`, `atkinson-hyperlegible-next-latin-ext-wght-normal.woff2` | all slide text | SIL Open Font License 1.1, `OFL-atkinson-hyperlegible-next.txt` |
| JetBrains Mono, by JetBrains ([source](https://github.com/JetBrains/JetBrainsMono)) | `jetbrains-mono-latin-wght-normal.woff2`, `jetbrains-mono-latin-ext-wght-normal.woff2` | code, terminal lines, addresses | SIL Open Font License 1.1, `OFL-jetbrains-mono.txt` |

Both are variable fonts (one file covers every weight), split into a Latin and a Latin Extended subset. The Latin Extended file carries the Turkish letters ğ, ş and İ.
